## Requirements 

```
pip3 install plotly
```

## How to Install

```
git clone https://github.com/Michael-Sebero/Numerology-Calculator

cd Numerology-Calculator && bash numerology-calculator
```

### Birthdate Calculator
This python script calculates your Life Path, Soul Urge, Expression, Personality, Physical Plane, Mental Plane, Emotional Plane and Intuitive Plane via Pythagorean Numerology and Planes of Expression. 

### Date Calculator
This Python script analyzes any calendar date, month or year with Greek Pythagorean numerology and Hebrew gematria (the date written in Hebrew numerals, read by mispar hechrachi, mispar katan and bone'eh), plus a Greek ⊕ Hebrew synthesis number. Year mode also saves a text report and an interactive graph.

### Master Number Name Generator
This python script will generate names which equate to master number values, ranked by how many master numbers each name produces.
